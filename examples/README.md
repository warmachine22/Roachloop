# Roach Loop example corpus

These examples demonstrate how the same protocol applies to different risk shapes.

- `web-app/` — visible product flow with UI, accessibility, and adversarial review.
- `api/` — headless behavior with no UI gate.
- `migration/` — data-integrity checkpoint with migration provider evidence.

Each example contains a small product statement, structured requirements, and the exact Roach commands that would initialize the build. They are intentionally small enough to clone into a scratch repository and execute.
