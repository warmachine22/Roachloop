A full assurance stack, not a bigger prompt.

Roach Loop moves process memory and evidence bookkeeping out of Claude/Codex prompts and into deterministic software.

The seven layers

Trusted core

State machine, Git binding, evidence hashing, tamper-evident ledger, seals.

Traceability

Requirements, checkpoints, files, tests, findings, decisions, redirects and releases.

Assurance

Risk profiles, independent reviewers, human approval, audit, specialized provider gates.

Freshness

Relevant-file snapshots, change impact, stale-proof detection and why-green/why-not-green.

Agent efficiency

Role-specific context packets with budgets instead of reloading the project history.

Portability

Open JSON schemas, external evidence providers, machine-readable reports and releases.

Operations

CI, pre-push checks, doctor, capability detection, benchmarks and threat modeling.
