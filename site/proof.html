Clone the repository and independently inspect the protocol, run the hostile test suite, and ask Roach for its own capability model.

1. Clone and test

git clone https://github.com/warmachine22/Roachloop.git
cd Roachloop
python3 -m unittest discover -s tests -v

2. Inspect the executable capability registry

python3 scripts/roach.py capabilities --json

3. Read the security model

See THREAT-MODEL.md, ROACH-PROTOCOL.md, the schemas under schemas/, and the provider contract under providers/.

4. Verify any Roach-managed project

python3 scripts/roach.py verify-project
python3 scripts/roach.py freshness --json
python3 scripts/roach.py report

The verifier reconstructs the ledger, traceability, evidence manifests, architecture constraints, secret checks, and freshness without asking an AI model whether the AI followed the process.

python3 scripts/roach.py why CP-014 --json
