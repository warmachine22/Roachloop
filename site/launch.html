GET STARTED

The easiest install is:
tell your agent to do it.

Paste the prompt below into Claude Code, Codex, or another coding agent while it is working in your project repository.

1. Copy this setup prompt

I want you to install and configure Roach Loop in this repository.

Roach Loop repository:
https://github.com/warmachine22/Roachloop

Read the Roach Loop documentation and protocol first.

Then:
1. Install Roach Loop into this project.
2. Initialize it for this project.
3. Inspect the existing repository and understand what the product currently does.
4. Help me turn my product intent into durable Roach Loop requirements and checkpoints.
5. Preserve existing work. Do not rewrite or delete project history just to fit the workflow.
6. Use Roach Loop as the assurance workflow for substantial development.
7. Never fabricate, manually pass, or bypass Roach-managed evidence or gates.
8. Run Roach Loop's doctor/status checks and tell me clearly if anything needs my decision.
9. Once configured, explain in plain English what was set up and what I should do next.

I am the authority on product intent and subjective acceptance.
You may implement and review work, but deterministic facts must be verified by Roach Loop.

2. For everyday work, paste this

This project uses Roach Loop.

Before substantial work, run:
python3 scripts/roach.py next

Load the active checkpoint context for your role.
Work only against the declared requirements and checkpoint.
Do not manually edit Roach-managed state or fabricate evidence.
Use Roach Loop to execute verification and record proof.
Resolve stale, failed, or missing evidence instead of bypassing it.
Before claiming completion, run:
python3 scripts/roach.py verify-project

If you need a product decision, ask me. Otherwise continue the Roach Loop.

3. Switching to a different coding agent?

Open the same repository in the new agent and give it this:

This repository uses Roach Loop and may have been worked on by another coding agent.

Do not assume prior chat context.
Treat the repository and Roach Loop state as the durable source of project context.

Run:
python3 scripts/roach.py doctor
python3 scripts/roach.py status
python3 scripts/roach.py next

Read the relevant Roach Loop context packet and continue from the recorded project state.
Do not redo completed work unless its evidence is stale or invalid.

Manual install

If you prefer to do it yourself:

git clone https://github.com/warmachine22/Roachloop.git
cd Roachloop
python3 -m unittest discover -s tests -v

# Or copy/install Roach Loop into your existing repository
./install.sh
python3 scripts/roach.py init --name "My Product"
python3 scripts/roach.py doctor
