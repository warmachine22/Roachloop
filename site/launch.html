LAUNCH

Give your coding agent a smaller rulebook.

Roach Loop moves process enforcement into software so Claude or Codex can spend context on the code.

Clone

git clone https://github.com/warmachine22/Roachloop.git
cd Roachloop
python3 -m unittest discover -s tests -v

Initialize a project

python3 scripts/roach.py init --name "My Product"

Add intent and a checkpoint

python3 scripts/roach.py requirement add FR-001 "User can sign in"
python3 scripts/roach.py checkpoint add CP-001 "Sign in" --requirements FR-001 --verify "pytest -q tests/test_login.py"
python3 scripts/roach.py start CP-001
python3 scripts/roach.py verify CP-001

Agent instruction

This repository uses Roach Loop.
Run python3 scripts/roach.py next before substantial work.
Use context <checkpoint> --role worker.
Never manually edit Roach-managed gate state.
Run verify-project before claiming completion.

Independent check

python3 scripts/roach.py verify-project

That check is deterministic; it does not ask an AI whether the AI followed the process.
